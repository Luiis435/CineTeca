📘 Guia de Uso

[ Ocultar ]

1. Busca

Use a barra de busca para encontrar rapidamente uma moeda pelo nome (Ex: "Bitcoin") ou ticker (Ex: "BTC").

2. Filtros Dinâmicos

Alterne entre "Top 50" para maior segurança ou o "Top 250" para maior diversidade de risco.

3. Indicador RSI

RSI ≤ 35 indica sobrevenda (potencial reversão). Linhas verdes claras indicam Top 50 com sobrevenda.
